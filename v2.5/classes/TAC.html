    registerChannel

    • registerChannel(channel: BaseChannel): void

      Register a channel with the framework, routing its inbound messages to the TAC.onMessageReady callback and shutting it down with TAC.shutdown.

      TACServer registers the channels passed to it (voiceChannel / messagingChannels), so you only need this when wiring channels into your own web framework instead of TACServer.

      Only one channel per type is registered: registering a different instance of the same type shuts down and replaces the existing one. Registering the same instance again is a no-op.

      Parameters

      • channel: BaseChannel

      Returns void

    onInterrupt

    • onInterrupt(callback: InterruptCallback): void

      Register callback invoked when the caller interrupts the agent on a voice call.

      Currently fired by the ConversationRelay voice provider. The callback receives conversationId, the call's session, utteranceUntilInterrupt (the text the agent had spoken when interrupted) and durationUntilInterruptMs (how long it had been speaking); either of the last two may be undefined if ConversationRelay doesn't report it. Errors thrown by the callback are logged, not rethrown.

      Parameters

      • callback: InterruptCallback

      Returns void

      Example

      tac.onInterrupt(({ conversationId, utteranceUntilInterrupt, durationUntilInterruptMs }) => {
        console.log(
          `${conversationId} interrupted after ${durationUntilInterruptMs} ms: ` +
            JSON.stringify(utteranceUntilInterrupt)
        );
      });

          Pending handoff payload set by the handoff tool. Voice channel sends this as a WS "end" message after the LLM's final response.

          Cached memory for "once" mode. Set on the first retrieval, cleared when the conversation becomes INACTIVE. Not persisted/serialized.

      • Optionalquery: string

        Optional semantic search query

      • OptionalconversationId: string

        Passed through to /Recall as-is. Sending one without a query makes Memory infer one from that conversation's history — an expensive server-side step — so leave it unset when there is no per-turn topic (e.g. "once" mode's cache-priming fetch).

      Promise containing TACMemoryResponse wrapper providing unified access to memory data.

      Attempts to retrieve from Memory API first:

      • observations, summaries, and communications available
      • communications include author name and type

      Falls back to Conversations API on error:

      • observations and summaries are empty arrays
      • communications have basic fields only (no author name/type)
