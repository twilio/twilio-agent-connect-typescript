    OptionalmachineDetection

    machineDetection?: "Enable" | "DetectMessageEnd"

    Enables AMD. 'Enable' reports as soon as it can tell human from machine (to hang up on voicemail); 'DetectMessageEnd' waits out the greeting (to leave a message). Required, together with asyncAmd, for onAmd to fire.

    OptionalasyncAmd

    asyncAmd?: string | boolean

    Detect in the background. Required for onAmd: with it off, AnsweredBy comes back on the TwiML request, which inline TwiML can't receive.

    Twilio's API types this as a string; a boolean is serialized for you.
